# 02 · Identidade Visual (estilo marca premium americana)

> ⚠️ Você já tem as artes prontas. Use esta página para **manter consistência** e conferir se bate com a logo oficial. Ajuste os hex se a logo real usar outro tom.

## 🎨 Paleta de cores (premium · água · confiança)

| Uso | Cor | HEX | Quando usar |
|---|---|---|---|
| Primária (marca) | Azul Profundo | `#0A2A43` | Fundos, texto forte, autoridade |
| Secundária | Azul Pure | `#1E6FB8` | Botões, destaques, links |
| Acento | Aqua / Ciano | `#36C5D0` | Detalhes, "água", energia, CTAs |
| Base clara | Branco Gelo | `#F4FAFE` | Fundo limpo, respiro |
| Neutro | Cinza Névoa | `#8FA3B0` | Textos secundários, legendas |
| Sucesso/Saúde | Verde Suave | `#2EBF8F` | Selos "garantia", "aprovado" |

**Regra 60/30/10:** 60% claro (branco/azul claro), 30% azul profundo, 10% aqua de acento. Isso cria o "ar premium" — muito espaço em branco, pouca poluição.

## ✍️ Tipografia
- **Títulos (impacto):** *Montserrat Bold* ou *Poppins SemiBold* — moderna, corporativa, limpa.
- **Texto/corpo:** *Inter* ou *Open Sans* — legível em telas pequenas.
- **Acento/número de impacto:** *Montserrat Black* para dados ("99% de contaminantes removidos").
- Nunca mais de 2 famílias por arte. Hierarquia por peso e tamanho, não por fonte nova.

## 📐 Padrão visual do feed (grid premium)
Estilo: **clean, arejado, fotográfico**, com selos discretos da marca.

**Padrão de cores em sequência (3 colunas):**
```
[ Foto produto ]   [ Card azul c/ frase ]   [ Foto família/água ]
[ Card dado/stat ] [ Foto antes/depois ]   [ Card azul c/ frase ]
[ Foto lifestyle ] [ Card depoimento ]     [ Foto produto ]
```
- Alterne **foto → card de texto → foto** para um feed equilibrado.
- Todo card de texto: fundo `#0A2A43` ou `#F4FAFE`, faixa aqua, logo no rodapé.
- Marca d'água/logo discreta no canto de TODA arte = profissionalismo.

## 🖼️ Banner visual / capa (para Reels fixados e destaques)
- Faixa superior azul profundo com a logo + "Representante Oficial".
- Gota d'água estilizada como elemento gráfico recorrente.
- Foto de água cristalina ou copo d'água limpo como pano de fundo.

## 🎯 Capas dos Destaques (Highlights)
Estilo único e coeso: **ícone branco minimalista sobre círculo azul profundo `#0A2A43`** com fino anel aqua.

| Destaque | Ícone sugerido |
|---|---|
| Sobre Nós | 👤 / silhueta |
| Benefícios | ✨ / estrela |
| Antes e Depois | 🔄 / setas |
| Clientes | 👨‍👩‍👧 / pessoas |
| Instalações | 🔧 / chave |
| Depoimentos | 💬 / balão |
| Promoções | 🏷️ / etiqueta |
| FAQ | ❓ / interrogação |
| Contato | 📞 / telefone |
| Qualidade da Água | 💧 / gota |
| Saúde | ❤️ / coração |
| Tecnologia | ⚙️ / engrenagem |
| Garantia | 🛡️ / escudo |

> Mantenha TODAS as capas no mesmo fundo e mesmo estilo de ícone. Consistência = percepção premium.

## 📏 Especificações técnicas de arte
- **Post quadrado:** 1080×1080px
- **Post retrato (mais alcance):** 1080×1350px ← priorize
- **Reels/Stories:** 1080×1920px
- **Capa de destaque:** 1080×1920 (centralize o ícone no meio para não cortar)
- Exporte em PNG/alta qualidade. Margem de segurança de 120px nas bordas.
