## 🔄 Como exportar para PNG/JPG (3 opções)
1. **Canva:** Upload do SVG → "Editar" → ajustar fontes (Poppins p/ tech, serifada elegante p/ beauty) → exportar PNG.
2. **Figma:** arraste o SVG → selecione o frame → Export PNG 2x.
3. **Navegador:** abra o `.svg`, dê print/screenshot, ou use um conversor online (ex.: cloudconvert).

## 🔤 Fontes (instalar para bater 100% com a marca)
- **Tech/produto:** Poppins ou Century Gothic.
- **Beauty/lifestyle:** serifada elegante (Cormorant, Playfair Display, Canela).
- Os SVGs já apontam para essas famílias com *fallback*; se não estiverem instaladas, o
  visualizador usa uma fonte padrão — troque no Canva/Figma para o acabamento final.
